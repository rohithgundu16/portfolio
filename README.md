# Gundu Rohith Dana Pavan — Personal Portfolio

A modern, responsive personal portfolio website built with **HTML5, CSS3 and vanilla JavaScript** only.
No frameworks, no build step — just open `index.html`.

## Folder structure

```
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── images/
    ├── profile.jpg
    ├── project1.jpg
    ├── project2.jpg
    ├── project3.jpg
    └── certificates/
```

## Sections

Navigation · Hero · About · Education · Skills · Projects · Certifications · Achievements · Activities · Contact · Footer

## Features

- Sticky responsive navbar with a JavaScript hamburger menu
- Smooth scrolling and active navigation highlighting
- Scroll reveal animations (IntersectionObserver)
- Modern cards, badges, timeline and hover effects
- Contact form with client-side validation (no backend needed)
- Fully responsive: mobile, tablet and desktop
- CSS variables, Flexbox and CSS Grid

## Run locally

1. Download the `portfolio` folder.
2. Open it in VS Code.
3. Double-click `index.html` (or use the Live Server extension).

## Deploy with GitHub Pages

1. Create a new GitHub repository (for example `portfolio`).
2. Upload **all files and the `images` folder**, keeping `index.html` in the repository root.
3. Go to **Settings → Pages**.
4. Under *Source*, select branch `main` and folder `/ (root)`, then **Save**.
5. Your site goes live at `https://<your-username>.github.io/<repository-name>/`.

## Customising

- Replace `images/profile.jpg` with your own photo (square image works best).
- Replace the project images with real screenshots.
- Add certificate images inside `images/certificates/`.
- Colors and spacing live in the `:root` variables at the top of `style.css`.
- Add GitHub links inside the project cards in `index.html` when the repositories are published.
